# Dijex — промпты для реализации (v2, с мультиязычностью)

Порядок: P1–P5 — фундамент (строго по порядку), P6–P22 — секции и страницы (любой порядок), P23–P24 — финал.
**Перед каждым промптом вставляйте блок P0.**

## P0 — Общий контекст (вставлять перед каждым промптом)

```
Работаем только в папке dijex-web-ui (React 18 + Vite + TS strict + Tailwind 3 + Framer Motion + lucide-react + i18next).
Перед работой прочитай dijex-web-ui/CLAUDE.md, dijex-web-ui/docs/content-plan.md (разделы 0–4) и этот промпт целиком.

Правила проекта:
- Только именованные экспорты, один компонент — один файл PascalCase.tsx, пропсы через `type Props`, без React.FC, без any.
- Классы — через cn() из @/lib/cn. Inline style — только для динамических значений.
- Цвета — только токены (bg-bg-base, bg-bg-surface, text-text-secondary, accent-primary, accent-secondary, accent-glow, border-border…).
- Шапка секции — компонент SectionHeader. Секция: <section id="..." className="scroll-mt-20 py-24 md:py-32">, внутри <Container>.
- Карточки: rounded-2xl border border-border bg-bg-surface/60 p-6 backdrop-blur-sm; hover: border-accent-primary/40 + shadow-glow + подъём.
- Анимации: FadeIn / ScrollReveal + revealItemVariants (stagger 0.08–0.12); всё корректно при prefers-reduced-motion.
- Картинки — только через <ImageSlot image="..."> с ключами из src/content/images.ts.

Мультиязычность (обязательно для каждого промпта):
- Поддерживаемые языки: en (fallback и эталон структуры), ru, th, zh (упрощённый), ja, fr, de.
- В компонентах и src/content/*.ts НЕТ пользовательского текста. Все строки (включая aria-label, alt, title,
  placeholder, сообщения валидации, meta) — в src/locales/<lang>/<namespace>.json и выводятся через t()/useTranslation.
- src/content/*.ts описывает только структуру: id, порядок, иконки, ключи картинок, ссылки, ключи переводов.
- Тексты в промптах даны на русском как исходник смысла. Ты кладёшь их в ru, делаешь качественный английский
  (en — эталон), затем переводы на th, zh, ja, fr, de. Переводы — естественные, маркетинговые, не дословные;
  термины AI/CRM/API/SDK/RAG оставлять латиницей. Названия брендов (Telegram, WhatsApp…) не переводить.
- Ключи одинаковые во всех 7 локалях (это проверяет тест). Неподтверждённые цифры/утверждения дописывай
  в docs/i18n-todo.md (JSON не поддерживает комментарии): «ключ — что уточнить».
- Числа и даты — через Intl с текущей локалью.
- Вёрстка должна выдерживать длинный немецкий/французский и плотный тайский/китайский/японский текст.

В конце: npm run lint, npx tsc --noEmit, npm run test — всё зелёное. Отчёт: что сделано + список новых/изменённых файлов.
```

## P1 — Починить токены цветов (прозрачность) и убрать захардкоженные цвета

```
Проблема: в tailwind.config.ts цвета заданы как 'var(--x)', а переменные — HEX. Из-за этого модификаторы
прозрачности (bg-bg-surface/60, border-border/40, bg-accent-primary/10, hover:bg-accent-primary/90, border-success/30…)
НЕ генерируются: фон карточек/формы/бейджей прозрачный, border-t секций и рамки иконок — дефолтный #E5E7EB
(яркие белые линии).

1. В globals.css переведи цветовые переменные в RGB-каналы: `--bg-base: 10 11 20;`.
2. В tailwind.config.ts: `'rgb(var(--bg-base) / <alpha-value>)'` для всех токенов.
3. Прямые использования var(--…) (:focus-visible, ::selection) → rgb(var(--…)).
4. В @layer base: `*, ::before, ::after { border-color: rgb(var(--border)); }`.
5. Захардкоженные rgba/HEX (ORBS в HeroBackground, радиальные свечения в About/Cases/ServiceCard, линия в Hero,
   SVG-сетки) вынеси в утилиты tailwind (backgroundImage: glow-indigo, glow-cyan, hero-mesh, dot-grid) и/или
   @layer components (.glow-behind). Inline style — только для динамики.
6. Сетку из About (inline data-URI) замени на bg-grid-pattern.
7. Проверь в браузере: разделители тёмно-синие, карточки и форма полупрозрачные со стеклом, поля ввода тёмные.

Критерии: нет классов /NN, которые не генерируются; нет светло-серых линий; lint/tsc/test зелёные.
```

## P2 — i18n-инфраструктура, JSON-переводы и новый контентный слой

```
Цель: заложить мультиязычность на 7 языков и перенести весь существующий текст сайта в JSON-переводы.

1. Зависимости: i18next, react-i18next, i18next-resources-to-backend. Детектор пишем сами (п.4), без внешних
   геосервисов и без IP-геолокации.

2. Структура переводов (namespace = смысловой блок):
   src/locales/
     en/ common.json   (навигация, кнопки, футер, 404, общие aria-подписи, названия языков)
         home.json     (все секции главной; вложенные объекты по секциям: hero, solutions, orchestrator, …)
         solutions.json(три страницы решений: ai-orchestrator, support-agent, digital-processes)
         form.json     (форма, валидация, тосты, успех)
         meta.json     (title/description страниц, og)
         legal.json    (privacy, thanks)
     ru/ … th/ … zh/ … ja/ … fr/ … de/  — те же файлы и ключи.
   Ключи — camelCase, вложенность по смыслу: home.hero.title, home.solutions.items.orchestrator.bullets (массив).
   Массивы допустимы (returnObjects: true), но у элементов списков-карточек — стабильные id-ключи, не индексы.

3. src/i18n/
     config.ts        — SUPPORTED_LOCALES = ['en','ru','th','zh','ja','fr','de'] as const; type Locale;
                        DEFAULT_LOCALE = 'en'; LOCALE_META: { code, nativeName, englishName, flag (код страны),
                        htmlLang ('zh-Hans' для zh), dir: 'ltr', fontClass }:
                          en English (GB) · ru Русский (RU) · th ไทย (TH) · zh 简体中文 (CN) · ja 日本語 (JP) ·
                          fr Français (FR) · de Deutsch (DE)
     detectLocale.ts  — чистая функция (см. п.4), покрыта тестами.
     i18n.ts          — инициализация i18next: fallbackLng 'en', ns, defaultNS 'common', interpolation.escapeValue false,
                        en грузится синхронно (в бандле), остальные локали — лениво через resourcesToBackend
                        + dynamic import(`../locales/${lng}/${ns}.json`) (отдельные чанки Vite).
     types.ts         — module augmentation react-i18next (CustomTypeOptions.resources = typeof en-ресурсов),
                        чтобы t('home.hero.title') был типизирован и опечатки ловил tsc.
     useLocale.ts     — хук { locale, setLocale(l), isChanging }: меняет язык, сохраняет выбор, обновляет
                        <html lang>, класс шрифта на <html>, document.title/description (через P5 useDocumentMeta).
   Подключи в main.tsx до рендера; App обёрни в <Suspense> с фолбэком-фоном (без мигающего спиннера).

4. Определение языка (detectLocale), по приоритету:
   а) явный выбор пользователя из localStorage 'dijex.locale' (в try/catch — хранилище может быть недоступно);
   б) параметр ?lang=xx в URL (для шаринга ссылок; после применения убрать из адресной строки через replaceState);
   в) язык региона браузера: navigator.languages по порядку, берём основной подтег (th-TH → th, zh-CN/zh-SG → zh,
      zh-TW/zh-HK → zh, ja-JP → ja, de-AT/de-CH → de, fr-CA/fr-BE → fr, ru-* → ru, en-* → en);
   г) регион по часовому поясу Intl.DateTimeFormat().resolvedOptions().timeZone, если язык браузера не поддержан:
      Europe/Moscow, Europe/Minsk, Asia/Almaty… → ru; Asia/Bangkok → th; Asia/Shanghai, Asia/Hong_Kong,
      Asia/Taipei, Asia/Macau → zh; Asia/Tokyo → ja; Europe/Paris → fr; Europe/Berlin, Europe/Vienna, Europe/Zurich → de;
   д) иначе 'en'.
   Важно: если язык браузера определён, но не поддержан (например pt-BR) — НЕ угадываем по часовому поясу
   с другого континента; таймзона используется только как сигнал региона для неподдержанных языков, иначе en.
   Тесты (Vitest): 'th-TH' → th; ['pt-BR','en-US'] → en; ['zh-TW'] → zh; пусто + Asia/Tokyo → ja;
   localStorage 'de' перекрывает navigator 'ru'; невалидное значение в localStorage игнорируется; всё упало → en.

5. Шрифты под языки:
   — Inter не содержит тайский и CJK, Sora — кириллицу (проверь по @fontsource/sora/unicode). Добавь
     @fontsource/noto-sans-thai, @fontsource/noto-sans-sc, @fontsource/noto-sans-jp (веса 400/500/700; fontsource
     даёт unicode-range-сабсеты — браузер качает только нужные глифы).
   — В tailwind fontFamily: sans/display получают fallback-цепочки; в globals.css правила по :lang():
     :lang(th) — Noto Sans Thai, line-height ×1.15 для body/заголовков;
     :lang(zh-Hans) — Noto Sans SC; :lang(ja) — Noto Sans JP;
     :lang(ru) — заголовки font-display падают на Inter (у Sora нет кириллицы), чтобы не было смешения гарнитур.
   — Для th/zh/ja у eyebrow-подписей отключить uppercase и уменьшить tracking (капс и разрядка для этих письменностей
     не работают): сделай это в SectionHeader через :lang() или класс на <html>.
   — Для de/fr: hyphens: auto на заголовках и карточках (работает благодаря корректному html lang).

6. Новый контентный слой (структура без текста):
   src/content/
     images.ts   — манифест изображений: { key: { src, width, height, altKey } } (alt — ключ перевода);
                   все файлы из раздела 4 content-plan.md; CHANNEL_LOGOS отдельно.
     nav.ts      — пункты меню (id, href, labelKey), группа «Решения».
     home/*.ts   — по файлу на секцию: порядок, id элементов, иконки, картинки, ссылки, ключи.
     solutions/*.ts + solutions/index.ts (getSolutionBySlug).
   Иконки — строковые ключи; маппинг на lucide — src/components/ui/iconMap.ts (расширь ICON_MAP из ServiceCard
   всеми иконками, упомянутыми в P6–P22).

7. Перенеси ВЕСЬ текущий текст (landing.ts, Header, Footer, ContactForm, Field-подписи, Toast-aria, PrivacyPage,
   ThanksPage, skip-link «Перейти к основному контенту», aria-label кнопок меню, index.html description) в JSON
   всех 7 языков. landing.ts удали. index.html: title/description оставь английскими (стартовые до загрузки JS).
   Существующие картинки public/*.png не трогай; в отчёте — таблица «старое имя → новое имя».

8. Тест целостности переводов src/locales/locales.test.ts: для каждой локали и namespace множество ключей (включая
   вложенные и длины массивов) совпадает с en; нет пустых строк; нет плейсхолдеров интерполяции, которых нет в en.

9. Вычитка: создай docs/i18n-todo.md — список того, что надо проверить носителю (th, zh, ja — целиком, и все
   маркетинговые заголовки), плюс TODO по цифрам.

Критерии: сайт выглядит как раньше на en и ru; смена языка в консоли (i18n.changeLanguage('ja')) переводит
всё без перезагрузки; в бандле en — синхронно, остальные локали — отдельными чанками; tsc ловит неверный ключ.
```
