## 2. Юридические формулировки (юрист)

- Соответствие законам о данных: в каждой локали своя формулировка — 152-ФЗ (ru), PDPA (th), PIPL (zh),
  APPI (ja), RGPD (fr), DSGVO (de), GDPR (en). Формулировка «проектируем с учётом», без заявления о сертификации.
- Согласие под формой и страница `/privacy` — сейчас заглушка на всех языках.

## 3. Контакты

- `hello@dijex.tech`, `+7 (999) 123-45-67`, соцсети — похожи на заглушки (`content/nav.ts`).

## 4. Вычитка носителями

- **th, zh, ja** — рекомендуется вычитать целиком.
- **fr, de** — заголовки и маркетинговые формулировки.
- Демо-диалоги чата (`content/home/support.ts`) не переводятся — это намеренно разные языки; японский
  сценарий уже вычитан агентом-переводчиком, но финальная проверка носителем желательна.
- Для китайской аудитории стоит подумать о каналах: часть мессенджеров (WhatsApp, Telegram, LINE)
  в материковом Китае недоступна.
